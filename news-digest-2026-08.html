AI Coding字节两篇 coding-agent 论文：Harness-IF 与 Lost in Compaction 揭示可靠性短板

8/26 两篇围绕 coding agent 可靠性的论文引发关注。其一是 Harness-IF，在 12 个前沿模型、60 个多轮编码任务上测试"指令跟随"：当规则与模型默认行为相悖（写在 system prompt、tool 描述、skill、项目文件、用户指令等多处）时，所有模型得分都明显变差——揭示 Agent 的"指令跟随"高度依赖表面默认。其二是 Lost in Compaction：长会话被压缩成摘要时，当前压缩器平均只保留 17% 的"会话级约束规则"（如"发邮件前先问我"），导致 Agent 记得任务却丢了规则；用一个 9B 抽取器把规则存进独立 registry，保留率回升到 90%+。

  • Harness-IF：12 个前沿模型 × 60 个多轮编码任务，对抗默认规则的指令全部得分下降
  • Lost in Compaction：3 种长上下文设置下，压缩器平均仅保留 17% 会话级约束规则
  • 修复方案：独立规则 registry + 9B 抽取器，保留率 >90%
当 Agent 长时运行、调用工具、替你发邮件，"会话规则"必须当持久状态存，而非丢进会被压缩的聊天历史。
