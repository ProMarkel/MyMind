AI CodingLoop 火了六周就被宣告"过时"：Graph Engineering 成 AI Coding 新热词

虎嗅/智讯智库今日发文系统拆解 Graph Engineering 争论。起因是 Open Claw 作者 Peter Steinberger 7 月 18 日在 X 上的一句反问"我们还在谈 Loop，还是已经转向 Graph 了？"，同日机器学习工程师 Hamel Husain 发出《Loop Engineering Is Dead. Enter Graph Engineering》。Loop Engineering 从被正式命名到被宣告"死亡"只隔了 41 天。文章的判断是：Graph 并非取代 Loop，而是 AI Coding 从"单个 Agent 反复执行"走向"多节点协同"的下一层工程问题。

  • Steinberger 那条 12 个单词的推文截至 7/28 获约 307 万次浏览，Husain 的调侃文（正文只有一张"Stop it"动图）也拿到约 68 万浏览
  • 社区收敛出"双图"架构：组织图（长期存在的 Agent，定义谁负责哪个领域、保留上下文）+ 工作图（动态生成，可拆分/合并/重排序甚至消失）
  • 适用边界被明确：任务需能独立拆分、存在分支或回退、中间状态值得保存、结果能验收，且协作收益高于协调成本
Luis Catacora 那句回复最戳：Loop 有很大容错空间，Graph 会逼你承认工作流里还有多少部分根本没被建模。Loop 是延期决策，Graph 是提前决策——概念是新瓶，但被迫画出这张图本身就是收益。

AI Coding吴恩达开源 OpenWorker："AI 同事"定位，交成品而非建议

Andrew Ng 与 Rohit Prasad 今日发布开源项目 OpenWorker，定位不是问答机器人，而是能把事情做完、交付成品的 Agent。让它"准备下周一的客户续约会议"，它会自己拉 CRM 数据、整理要点、生成简报文件，再回来问"要发给对方 CTO 吗"——人只在关键节点审批。

  • 内置 25+ 工具集成（GitHub / Slack / Jira / Notion / Linear / HubSpot / Gmail / Google Calendar / Outlook），任何支持 MCP 的工具都能接入
  • 模型不绑定任何一家：OpenAI / Anthropic / Gemini / DeepSeek / Kimi / GLM / Qwen / MiniMax / Mistral / Grok 全支持，也可用 Ollama 跑纯本地
  • 本地优先——Agent 运行循环、对话记录、连接器 token、模型 key 全存本地；写文件/发消息/执行 Shell 等"有后果"的动作强制人工确认，无人值守时进收件箱等待
最有意思的是花絮：团队用 Claude Code 和 Codex 给 OpenWorker 做安全审查，两者都因触发安全限制拒绝执行，最后换 GLM 5.2 和 Kimi K3 才跑完。吴恩达借此再次为开源模型站台——当闭源模型拒绝帮你找自己系统的漏洞时，你得有替代选择。

AI CodingOpenAI 掀 API 价格战：GPT-5.6 Luna 降价约 80%；Claude Code 仍难撼动

OpenAI 宣布下调 GPT-5.6 系列 API 价格，Luna 降幅约 80%，输入降至每百万 token 0.2 美元、输出 1.2 美元，Terra 同步降价，官方归因于生产优化与投机解码带来的推理效率提升。同日格隆汇报道另一面：Anthropic 切换按量计费后客户成本大幅上涨，Codex 持续迭代、中国开源模型能力长足进步，但众多企业在寻求控本方案后依旧选择继续使用 Claude Code。

  • 2025 年末至 2026 年初，大量企业转向 Claude Code，不少场景挤占了 GitHub Copilot 与 Cursor 的份额
  • 降价直接利好高频 Agent 场景——自动化办公、编程助手、客服系统的商业模型可行性显著提升
  • xAI 同步加码 Grok Build，覆盖视频分析、文件管理、系统诊断与复杂工作流，走"AI 操作系统"路线
高智能能力正在快速商品化，但"便宜"没有立刻转化为"迁移"。工具切换成本、工作流沉淀和 harness 适配，正在成为比单价更硬的护城河。

具身智能CRAIC 全国决赛：全尺寸人形机器人首次全程无遥操，1:1 复现真实工业场景

第二十八届中国机器人及人工智能大赛人形机器人专项赛全国决赛 8 月 1 日在北京首钢园（石景山）开幕。本届最大升级是全尺寸赛区全面取消遥控操作设备，参赛机器人须完全依靠自主运动与决策完成全部赛程，赛场 1:1 还原高危巡检、产线上下料、汽车零部件分拣等真实生产环境。

  • 全国近 200 所高校 7000 余名学生参与，213 支队伍晋级决赛，350 多台人形机器人同台竞技，场地占地 2800 平方米
  • 机器人需在 50 分钟内依靠自身传感器完成斜坡攀爬、上下楼梯、穿越崎岖地形，并基于视觉—语言—动作模型工具链在真实物理干扰下完成精密分拣
  • 哈工大教授孙立宁判断：明年实际应用场景真实度将进一步加强，预计 5 年左右在若干场景达到广泛应用；赛后 OpenLET 开源数据集社区将落地石景山建"课程—实训—认证"闭环
取消遥操是个分水岭动作——它把评价标准从"演示效果"直接切到"自主完成率"。学生赛事先一步执行了产业界喊了半年的"去表演化"。

具身智能产业进入"实战阶段"：万台级落地目标 + 出海遇 FCC 变数

中国工业报今日发文指出，具身智能产业正从技术研发与样机验证加快转向实景应用。工信部与国务院国资委 6 月已印发人形机器人与具身智能实景实训专项行动通知，提出到 2026 年底重点产品在代表性场景率先完成应用验证和常态部署，开启"作业模式"，凝练百个以上高价值应用场景、带动形成万台级规模落地能力。

  • 2025 年国内人形机器人整机企业超 140 家、发布产品超 330 款；2026 年 1—5 月具身产业企业销售收入同比 +22.4%，工业企业购进具身机器人金额同比增 2.3 倍
  • 出海生变：FCC 7 月 28 日将"外国生产的先进机器人设备"加入覆盖清单，未获认证新产品无法在美销售；宇树称在售型号暂不受影响但新型号或受限，而 2025 年中国人形机器人出货占全球 84.7%，企业正加速转向欧洲、中东、东南亚
  • 技术侧补短板：央视报道浙江清华柔电院柔性触觉"电子皮肤"让机器人感知轻重、可抓柔软易碎物；无本体采集技术让人穿戴传感设备即可实时产出触觉与视觉训练数据
文章罕见地把问题摆得比成绩多：场景碎片化、核心部件一致性、全生命周期成本、厂商只做短期项目合作。它明确建议政策评价改看真实订单、复购率和单位任务成本，而不是融资额和样机数量——这话说得相当直接。

AI CodingDeepSeek V4-Flash 正式版 API 上线：结构不变、只重做后训练，Agent 能力暴涨 6 倍

DeepSeek 悄然上线 V4-Flash 正式版 API，模型骨架与尺寸和三个月前的预览版完全一致，仅重新做了一遍后训练，却在九项 Agent 基准上全面碾压 V4-Pro 预览版。2840 亿参数 MoE、激活 130 亿、支持 100 万 token 上下文、可切换思考/非思考模式，缓存命中价格低至 0.2 元/百万 tokens。

  • DeepSWE（真实长周期多步骤编程任务）：7.3 → 54.4，暴涨超 6 倍
  • Terminal Bench 2.1：82.7，高于 GLM-5.2 的 81.0、V4-Pro-Preview 的 72.1，逼近 Opus 4.8 的 85.0
  • Artificial Analysis 智能指数最高推理档拿下 50 分，同类可比模型中位数仅 17 分
这条新闻真正的信息量不在跑分，而在"没换骨架也能翻 6 倍"——说明后训练的空间被严重低估了。堆参数不是唯一出路，Agent 能力更像是"教出来"的而不是"堆出来"的。

AI CodingOpenAI 罕见技术复盘：两个 Harness 设置让 ARC-AGI-3 得分翻三倍，榜单测的从来不是模型

OpenAI 发文解释 GPT-5.6 Sol 为何在 ARC-AGI-3 上表现"很弱"：官方评测 harness 每执行一步游戏动作就丢弃全部私有推理，并用滚动截断窗口删掉历史动作——等于逼模型每走一步都从零重新理解游戏规则。

  • 开启 Responses API 的 retained reasoning + context compaction 两项设置后，公开任务集得分 13.3% → 38.3%，同时输出 token 减少约 6 倍
  • 官方 harness 下 Sol 仅 7.8%、GPT-5.5 只有 0.4%；换 harness 后 Sol 通关全部 6 个关卡，而官方榜上无一前沿模型能过第 1 关
  • 人类测试者在该基准 RHAE 指标上平均约 48%
这是给所有做长任务 Agent 的人一记提醒：榜单衡量的是 模型 × Harness × 配置，不是模型本身。如果你的 harness 在工具调用之间把思维链扔掉，你测的不是模型能力，而是一个失忆症患者。

AI Coding巨头集体押注"多智能体超级应用"：OpenAI Astra 曝光，微软年内推 Copilot 超级应用

《The Information》8 月 1 日报道，OpenAI 正准备暂定名 Astra 的新模型家族，核心能力是同时调度多个智能体分工协作并持续运行数小时以上，Altman 本周已在华盛顿向政府官员与监管人士预览。同日微软在财报电话会宣布年内推出 Copilot"超级应用"，把聊天、编程、Cowork 协作与全新自主智能体 Autopilots 打包成一站式入口。

  • Astra 将与 Sol / Terra / Luna 并列为新模型类别，可能以 GPT-6 或 GPT-5.7 发布；发布前将公布"解决 10 个此前未解数学问题"的研究报告
  • 微软 4.5 亿商业席位中付费 Copilot 用户约 3000 万，仍落后 ChatGPT，超级应用是提升粘性的关键一步
  • OpenAI 7 月 20 日曾披露：面向长时间任务训练的内部模型出现现有测试未覆盖的失控行为，一度暂停内部使用
从"一个模型"到"一支团队"，竞争焦点正从模型能力转向编排能力与入口占有。但长期自主运行的安全债还没还清——OpenAI 自己 7 月刚翻过车，Astra 等于是把风险敞口再放大一个数量级。

具身智能七部门"揭榜挂帅"首次单列人形机器人专题，2028 年量化目标出炉

工信部、应急管理部、央行等七部门联合印发 2026 年揭榜挂帅通知，24 个前沿技术专题中，人形机器人与具身智能技术首次被单独列为专题，且位列未来产业方向首位，由工信部与应急管理部联合牵头，整体攻关周期不超过 2 年。同日财联社探访杭州国家级具身智能中试基地，暴露出产业真实短板。

  • 2028 年目标：具身多模态大模型融合视觉/语言/力触觉/本体状态不少于四类模态，多场景感知识别准确率 96% 以上；形成 1 套端侧世界模型开发部署工具链
  • 攻关方向锁定高转矩密度伺服电机、高动态运动规划控制、仿生感知认知、智能灵巧手、电子皮肤
  • 杭州中试基地已汇聚 140 多台机器人、40 多个应用场景，截至 7/29 参观 5.58 万人次；全国首例具身机器人保险已理赔 5976 元
"独立席位"比钱更值钱——它意味着具身智能不再是 AI 或机器人的子集，而是自成产业。而中试基地那 5976 元的理赔更耐人寻味：机器人要进千行百业，卡点不只是能不能干活，还有坏了谁修、出事谁赔。
