AI Coding新基准 LSCB 揭穿 coding agent 安全短板：6 款前沿工具仅 25.1% 写出"既功能又安全"的代码

10 月 14 日，Hugging Face 上发布 Last Secure Code Benchmark（LSCB，"你 vibe 出来的代码安全吗？"）。研究者取 150 个真实漏洞 扩展为 450 个任务、覆盖 7 种语言与 24 类 CWE，让 6 款前沿 coding agent 在"只要求功能、不提安全"的真实简报下写代码——结果触目：功能测试通过率高达 73.6%–91.3%，但"功能且安全"的最高仅 25.1%（Claude Fable 5），其余 16.4%–24.7%；仓库级正确且安全的结果约 11.8%。作者强调这是默认行为，给定安全要求和自动 review 会显著改善。

  • 最强 agent 功能且安全仅 25.1%，其余 16.4%–24.7%；功能通过率却达 73.6%–91.3%
  • 覆盖 150 真实漏洞 / 450 任务 / 7 语言 / 24 CWE（含 21 项 2025 CWE Top 25）
  • Veracode 同期数据：150+ 模型安全通过率两年卡在 ~55%，XSS ~15%、日志注入 ~13%
当"能跑"与"安全"的落差被量化成 25% 这道坎，coding agent 的竞争重心必须从"会不会写"转向"写的是不是该上的线"——过程约束（安全 prompt + review 闸 + 依赖审查）比换模型更管用。

  • 真实样例：一步 27 token（压缩 CJK 速记）vs 基模 137 token
  • 基于 Qwen3.8-27B，Apache-2.0 开放权重，聚焦 token 效率前沿研究
当 agent 循环每天跑成千上万次推理，"省 token"不再只是省钱，而是决定多 agent 并行与长任务能否跑得起的关键变量——用领域压缩语言挤掉冗余思考，是比堆参数更聪明的降本路径。

AI Codinggroundcover 把生产可观测性经 MCP 接入 coding agent：让 Claude/Cursor/Codex 直接查线上遥测

observability 厂商 groundcover 推出面向 AI coding agent 的多面集成，经 Model Context Protocol（MCP） 把外部 agent（Claude、Cursor、Kiro、Codex）直接连到生产遥测——实时日志、指标与 trace，补上 agent 在"理解代码逻辑"之外缺失的"线上真实行为"证据。平台还引入异步 Agent Tasks：外部 agent 发现但无力诊断时，可把根因分析、看板生成等任务委派给 groundcover Agent 后台执行。全部能力走既有 BYOC 架构 + 单 eBPF 探针，遥测不出客户云。

  • 经 MCP 打通 Claude / Cursor / Kiro / Codex 与生产日志、指标、trace
  • 异步 Agent Tasks：外部 agent 可把根因分析 / 看板生成委派给 groundcover Agent 后台跑
  • 通过 BYOC + 单 eBPF 探针落地，遥测留在客户自有云，节点式计费避免高量 ingestion 成本
当 coding agent 从"写代码"延伸到"看线上"，上下文真空成了限制其自治的隐形天花板——把生产遥测做成 agent 可查询的协议层，是 agentic 软件开发生命周期真正闭环的一块基石。
