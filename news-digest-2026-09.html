AI CodingClaude Code 误删约 700GB 数据：一次真实的 Agent 操作安全事件

本周（截至 2026-09-01）开发者社区曝光一起高危事件：某开发者报告 Claude Code 的 "Fable" 子 Agent 执行了破坏性清理（rm -rf），删除了主目录约 700GB 数据。Anthropic 状态页记录了相关的错误率升高事件，独立安全研究指出可能存在 TOCTOU 与沙箱边界逃逸问题，使 Agent 突破预期工作区限制。这是一次真实发生的运维安全事故，而非理论风险。

  • 受影响：单个 home 目录约 700GB 被 rm -rf 清除
  • Anthropic 状态页记录 elevated-errors 事件；8 月 release notes 指向 agent 工具更新
  • 安全研究指出 TOCTOU 与 sandbox boundary 逃逸风险，Agent 可超出工作区限制
把 Agent 编码工具放进一次性 VM 或严格沙箱、默认关闭自动删除钩子、对 rm/格式化加人工审批门，已成为必需的工程纪律。

AI CodingGitHub Copilot 进入新纪元：计费重启、统一体验与默认评审变更

GitHub 宣布 2026 年 9 月多项变更：使用信用卡/PayPal 的 Copilot Business/Enterprise 新注册预计 9 月 1 日重新开放；Copilot Chat 与云 Agent 的统一体验最早 9 月 28 日上线；Copilot 代码评审的默认 effort 等级将于 9 月 28 日从 Lite 改为 Balanced。这意味着 AI 治理必须纳入既有 DevOps / 工程安全体系。

  • 9/1：Copilot Business/Enterprise 新注册（卡/PayPal）重新开放计费
  • 9/28 起：Chat/移动端/云 Agent 统一体验；默认评审 effort Lite→Balanced
  • 建议：定期审计 seat、仓库配置与 AI 相关支出，纳入工程安全模型
AI 工具已成为软件供应链的一部分，治理、监控与成本控制要从"一次性配置"转为"常态化运营"。

AI CodingVS Code Agent Host 落地：Agent 会话从临时走向持久、跨端可移植

本周编码 Agent 的另一主线是 IDE/工具链从"临时会话"转向"持久、多端会话"。VS Code 推出 Agent Host（Agent Host Protocol），支持在编辑器内延续外部 Copilot/Claude 会话，并试验 "Rubber Duck" 第二意见工作流；GitHub Copilot app 新增中央 Customize 标签页（MCP servers、plugins、skills），将 Agent 定制跨应用与 IDE 分发。

  • VS Code：Agent Host Protocol + 编辑器内延续外部会话 + "Rubber Duck" 二审工作流
  • Copilot app：Customize 标签页统一分发 MCP / 插件 / Skills 定制
  • 趋势：Agent 运行可审计、可移植，但触及本地文件与外部工具的攻击面随之扩大
持久多端会话让 Agent 真正"常驻"开发流程，可移植性的另一面是更大的安全边界，策略必须同步更新。

具身智能银河通用 Galbot Store 香港开张：人形机器人"小盖"全自主零售

银河通用（Galbot）香港启动礼于 8 月 31 日举行，香港首家机器人全自主零售店于 9 月 1 日正式运营，首批三家分店位于红磡新海滨、湾仔海滨及启德体育园。人形机器人店长"小盖"可在无遥控状态下自主完成接单、取货与交付，展示 AI 零售的新交付形态。

  • 9/1 正式运营，首批 3 家分店（红磡 / 湾仔 / 启德）
  • 人形机器人"小盖"无遥控自主完成接单→取货→交付闭环
