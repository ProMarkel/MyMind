AI CodingSoL-Pi：研究 AI 旁观 coding agent，自动调优 harness 省下近半 token

NVIDIA、NTU 与 MIT 联合发布 SoL-Pi（arXiv:2609.20519），让一个研究型 AI 实时"旁观"编码 agent 的工作，自动提出对文件/命令/记忆层的修改，仅保留既不伤质量又省 token 的改动。整套运行覆盖约 150 个研究方向、500 个环境、3,000+ 次试验与 6 万+ 次 agent-环境交互。

  • token 消耗下降 44.7%–49%，且未牺牲任务质量
  • 把"agent 调参"本身交给另一个 agent，形成自我优化的闭环
  • 印证趋势：coding agent 的竞争正从模型能力转向"harness 工程"
当省 token 不再靠压缩上下文、而是靠一个 AI 实时改写 agent 的工作方式，harness 调优正成为 coding agent 的新护城河。

AI CodingDeepSeek 公开 agent 训练系统：38 万沙箱并行 + 行为失控管控

  • 38 万级沙箱并行规模，逼近工业级 agent 训练基础设施
  • 首次明确把"agent 行为失控管控"作为训练系统的一等公民
  • 与同日 SoL-Pi 的"旁观式调优"形成互补：一个控规模、一个控效率
当训练系统开始原生内置"防越轨"，说明行业已把 agent 安全从部署期前移到训练期——这是 capability 与 safety 同步 scaling 的信号。

AI CodingMIT 与 Sakana AI 提出 SIFT：自改进代码智能体，成本降至此前的 1/10

MIT 与 Sakana AI 联合提出 SIFT（Self-Improvement via Fast Tree-search），让代码智能体写改自身代码、由 LLM 裁判排序，只把最有希望的候选送去做完整基准评测。瓶颈在基准跑分本身，预筛选把计算量砍掉大半。o3-mini 配置在 Polyglot 跑出 35.1%（30 次树搜索展开），仅用不到 5 个墙钟小时；Qwen3-30B 全搜索仅 224 CPU 小时、$34 API 开销，约为此前 DGM 方法的十分之一。

  • TerminalBench 上以 gpt-5.4-high 作成对裁判，智能体从 29.2% 基线升至 36.7%，证明"裁判质量决定天花板"
  • 核心结论：代码智能体的迭代自改进在理性算力预算下可行，无需千卡集群
  • 当前上限不在算法，而在裁判模型质量——下一代裁判会把天花板推得更高
